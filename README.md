Команда install выполняет npm ci
```bash
make install
```
Запуск файла brain-games.js, лежащего в директории bin корня проекта
```bash
make brain-games
```
Сухой запуск пробной публикации npm publish --dry-run
```bash
make public
```
Запуск eslint

```bash
make lint
```
