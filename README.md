### Hexlet tests and linter status:
[![Actions Status](https://github.com/Foxtery/frontend-project-44/actions/workflows/hexlet-check.yml/badge.svg)](https://github.com/Foxtery/frontend-project-44/actions)

Команда install выполняет npm ci
```bash
make install
```
Запуск файла brain-games.js, лежащего в директории bin корня проекта
```bash
make brain-games
```
Сухой запуск пробной публикации npm publish --dry-run
```bash
make public
```
Запуск eslint

```bash
make lint
```
